# Limitations

## 1. Sample-size Limitation

The dataset contains only six fictional service zones.

The number of locations reviewed is different in each zone, ranging from 4 to 10.

Zones with fewer reviewed locations have less supporting information. This makes comparisons less reliable.

## 2. Measurement Limitation

The access index is a fictional relative score on a 0–100 scale.

It does not measure the percentage of residents who can access services.

The data are synthetic and cannot be used to make real planning or resource-allocation decisions.

## 3. Classification Limitation

The maps use the Equal Interval classification method.

Part A uses 3 classes, while Part B uses 5 classes.

Different numbers of classes change how the differences between zones appear.

In Part B, Class 3 contains no zones. This shows that classification choices can affect how readers understand the map.

## 4. Geographic-scale Limitation

The map shows only six illustrative service zones.

Each zone has one index value, so the map does not show differences within a zone.

The results cannot be used to describe smaller neighbourhoods or individual locations.
