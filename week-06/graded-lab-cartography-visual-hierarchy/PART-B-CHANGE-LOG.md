# Part B — Change Log

## 1. Issue

Part A used three classes to show the access index values.

This made the map easy to read, but some zones with different index values appeared in the same colour.

I wanted to test whether using more classes would make these differences easier to see.

## 2. Exact Setting Changed

I changed only the number of classes.

- Part A: 3 classes
- Part B: 5 classes

Both maps used the Equal Interval classification method.

The original data, CRS, colour ramp, labels, and other map settings were kept the same.

## 3. Class Breaks

**Part A — 3 Classes**

- 34–52
- 52–70
- 70–88

**Part B — 5 Classes**

- 34–45
- 45–56
- 56–66
- 66–77
- 77–88

## 4. Comparison Results

Part B makes some differences clearer.

For example, Northwest and North Central were both in Class 1 in Part A. In Part B, they are in different classes.

South Central and Southeast were both in Class 3 in Part A. In Part B, Southeast is in a higher class.

However, Class 3 in Part B has no zones.

## 5. Accessibility Trade-off

Part A is simpler because it uses only three colours. It is easier to understand quickly.

Part B shows more detail, but five colours can be harder to distinguish.

Both maps use zone labels and a data table, so readers do not need to rely on colours alone.

## 6. Recommendation

I recommend Part A for a general audience.

Three classes make the main pattern easier to understand, while the data table provides the exact values.

Part B is useful for comparing smaller differences between zones, but it is more complex.

Neither map should be used for real resource-allocation decisions because the data are fictional.
